# Stellarium for Zed

Stellarium Script language support for [Zed](https://zed.dev/), backed by the
release-pinned `stellarium-lsp` language server and the standalone
[`tree-sitter-stellarium`](https://github.com/fits-ki/tree-sitter-stellarium)
grammar.

The repository is a reviewed distribution snapshot generated from the private
canonical Stellarium tooling monorepo. Changes should be contributed to the
canonical project rather than edited directly in this repository.

## Development

Install this repository as a Zed dev extension, then use Zed's **Rebuild**
action after source changes.
